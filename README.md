# Index project

## Project Overview
This project is a web-based index that collects all of my projects from Typography and Interaction. Each project represents a different stage of learning HTML, CSS, and JavaScript — from typography and responsive layouts to APIs and interactive systems.

The interface organizes the five projects using folder-inspired cards. Each folder includes an icon related to its topic and uses the same colors assigned to each project in the original class syllabus.

The goal of the project was to create a simple archive system that visually communicates the progression of the course while introducing small interactive behaviors through CSS and JavaScript.

---

## Interaction System 
The interface changes depending on the device:

### Desktop
- Hovering over a folder reveals additional project information
- The colored tab expands upward to simulate an opened folder
- Project descriptions remain hidden until interaction

### Mobile
- Project information is always visible below the folder
- JavaScript and Intersection Observer detect when a project enters the viewport
- The folder tab expands automatically while scrolling
